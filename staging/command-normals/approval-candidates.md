# 方向入力で出す特殊技の承認候補

CAPCOM日本語公式フレーム表（CLASSIC、2026-11-10保存、対象パッチ未確認）。32キャラ分を確認し、109入力を候補にした。候補値は発生・空振り全体F・通常ヒット・ガードの順。Dはダウン。

地上で方向と攻撃ボタン1つから直接出せる技を対象とし、ターゲットコンボは単独入力で出せる初段のみ収録候補とした。初段には「†」を付けた。後続入力、連続方向入力、ジャンプ中・構え中・強化状態限定、同時押し、ホールド版を除外する。

ダルシムのロングスライディング（2HK）は既存のしゃがみ強Kと同一。ジェイミーの円月脚1段目（6MK）は同値の落星脚にまとめた。春麗の追突拳は公式表で4MPと6MPの両方が入力として示されている。

全体Fは公式表の空振り値、または持続最終F＋硬直に空振り時の明記補正を加えた値。各キャラのリンク先が出典。「行」は保存した公式表の行番号。
