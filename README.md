# SF6フレーム探偵

技のフレームデータを手がかりに、隠された『ストリートファイター6』のキャラクターを当てる推理ゲームです。ブラウザーで遊べます。

**[ゲームを遊ぶ](https://mukade-daiou.github.io/sf6-frame-guess/)**

## 遊び方

1. モードを選んでゲームを開始します。
2. 通常技や必殺技・SAの入力を指定し、フレームデータを質問します。
3. 最大5回の質問からキャラクターを推理して、回答します。途中で回答へ進むこともできます。

Normalでは発生・全体・ヒット時硬直差・ガード時硬直差を、Hardでは発生のみを表示します。難易度は最初の有効な質問をすると固定されます。

同じ入力は再質問できません。不明なデータは質問回数を消費せず、採用データ内に技がない場合は1回消費します。

## モードと結果の共有

通常モードは1問ずつ遊べます。連続モードでは正解すると次の問題へ進み、不正解・ギブアップで終了します。直近10問で正解したキャラクターは出題されません。

結果画面の「Xで結果をシェア」から、結果と質問履歴を入力した投稿画面を開けます。投稿は自分で確認して行えます。

## フレームデータについて

現在は32キャラクターに対応しています。ゲームには固定のデータを使っており、自動更新は行いません。

表示値は採用した代表条件に基づきます。距離によって発生が変わる技は、根拠が確認できた場合に範囲で表示します。実際の対戦条件によって値が異なる場合があります。

公式資料との照合には不一致や確認不能の項目があり、対象パッチも未確認です。最新バージョンの正確な数値を保証するものではありません。詳しくは[出典方針](docs/DATA_SOURCES.md)と[照合結果](docs/OFFICIAL_VERIFICATION_REEVALUATION.md)を参照してください。

## ローカルで動かす

Node.js 24とnpmを使用します。

```sh
npm ci
npm run dev
```

React・TypeScript・Viteで構築した、バックエンド不要のアプリです。

開発・検証・デプロイの手順とデータ管理の詳細は[開発ガイド](DEVELOPMENT.md)、詳しいルールは[ゲーム仕様](docs/GAME_SPEC.md)にまとめています。
