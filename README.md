# SF6フレーム探偵

技のフレームデータを手がかりに、『ストリートファイター6』のキャラクターを当てる非公式のブラウザーゲームです。

**[ゲームを遊ぶ](https://mukade-daiou.github.io/sf6-frame-guess/)**

「通常技・特殊技」か「必殺技・SA」の入力を選び、1問につき最大5回の質問でキャラクターを推理します。通常モードは1問ずつ、連続モードは正解するたびに次の問題へ進み、不正解かギブアップで終了します。

フレーム値は固定データの代表条件に基づきます。対象パッチは未確認で、実際の対戦条件によって値が異なる場合があります。データと操作アイコンの出典は[出典・帰属方針](docs/DATA_SOURCES.md)に記載しています。
