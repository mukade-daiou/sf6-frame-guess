## 6. ヒット値の意味

SuperCombo公開APIは[原典の表](https://wiki.supercombo.gg/w/Street_Fighter_6)を構成するCargoデータを返す。今回の取得ではリュウ2HKがKD +40、マリーザ236LPがKD +36だった。
それぞれ固定上流JSONの入力・注記・発生・数値部分と一致することを確認し、フレーム数を更新するのではなく、欠落していたKDの意味を復元した。

同じ照合条件を満たした採用候補230技を `confirmed/display:"D"`、numericなしに修正した。証拠となる原典表記（sourceDisplay）、取得日時、URL、元のonHitを保存した。
KD/HKDの明示表記がない数値は変換しない。例えば単なる+40はそのままである。パッチ不明な別表の数値を取り込んだわけではなく、特定の原典記録との対応に基づく意味の修正である。
これによってキャラやSourceのverificationをverifiedへ変更してはいない。230技以外の大きな正数、打ち上げ・壁バウンド等の扱いは追加検証が必要。

- `review-decisions.json`：原典レコード単位の判断を永続化。内容変更を検出するとStale reviewsで停止する。手動判断を新しいデータに無条件適用しない。
- `quality-report.json`：32体の前後件数、46キー、133項目、変更前後の全レコード、各技の未検証事項・URL、Zod結果。
- `characters/*.json`：856候補。`*.audit.json`：除外と適用判断。
- `evidence/`：原典、アクセス結果、取得時刻、比較先のバージョン。CC-BY-SA-4.0のNOTICEと帰属を保持。
