# ゲーム仕様

設定 → 質問 → 最終回答 → 結果 → 設定 の順で進みます。質問上限はロジックの設定値で、初期UIでは5回固定です。
ノーマルは発生・全体・ヒット時硬直差・ガード時硬直差を表示し、発生のみモードは発生だけ表示します。開始時はノーマル。質問・回答・結果のすべてのフェーズでパネル右上から切り替えられ、既存の全履歴も現在のモードで即時表示します。正解・質問数・履歴の記録自体は変わりません。

第10段階から、原典との対応・明確な矛盾の有無を基準に採用し、原典に基づく収録範囲がcompleteのキャラクターから等確率で抽選します。出典のverificationやパッチ確認とは独立したadoption判定を使います。公式・実機での100%検証は採用要件にしません。
同じ一覧が回答候補になります。2体未満では開始できません。キャラクターIDをコードに固定しません。

通常技はレバー中央（立ち）・下（しゃがみ）とP/K、L/M/H。必殺技はレバーの方向列とP/K、L/M/H/ODから選び、「質問する」で確定します。8ボタンは上段が弱P・中P・強P・弱P＋中P、下段が弱K・中K・強K・弱K＋中K。通常技では同時押しを無効化します。
必殺技の方向列はニュートラルで消えず、クリアで初期化します。同一方向の揺れは重複せず、一度離して同じ方向を入れる22等は保持します。時間制限・近似補正はありません。マウス／タッチのドラッグ、方向の個別タップ、方向キー・テンキーに対応し、離すとノブは中央へ戻ります（通常技は選択位置を保持）。
「質問する」を押した後は、成立・不明・重複にかかわらず入力済みコマンドと攻撃ボタンの選択をクリアします。通常技の立ち／しゃがみの選択は保持します。不明の短い結果表示、質問非消費、履歴・正解・モードは維持します。
必殺技で方向を入力すると、レバー下のコマンド表示・クリアのすぐ下に、その方向列で始まる対応モーションの候補を表示します。候補は出題対象全体から重複を除いて導出し、正解キャラでは絞りません。候補クリックで方向列を明示的に完成させ、攻撃ボタンは別に選びます。候補選択は質問を消費せず、自動補正・自動質問も行いません。未入力・不一致時は候補を表示せず、質問後やクリアで候補も消します。
モーションなし同時押し（奮迅脚）・溜め等の未対応表記・強度noneは今回の質問候補から除き、元レコード・スキーマは維持します。強度なしレコードと個別ボタンの対応が未確定の場合は技なしへ変換しません。
個々のキャラが持つ入力一覧はUIへ渡しません。入力候補は出題対象全体の採用された基本版から導出します。フレーム値の不明を理由に選択肢から除かず、質問時に必要な値を判定します。

検索は基本版だけを対象とし、複数ならambiguous、1件で採用済みかつ必要な値が表示可能ならfoundです。保留技・通常状態が不明の技はunknownです。
0件で採用データのそのカテゴリがcompleteならnot_found、それ以外はunknownです。技なしは採用データセット内での不存在を意味し、ゲーム本体の全パッチで不存在と主張しません。同じ入力の保留・条件版が記録されている場合もunknownとし、不存在へ変換しません。
標準条件は通常状態・原則立ちの相手・画面中央・通常ヒット/ガード・非ホールド・派生なし、全体Fは空振り時です。下段のガードはしゃがみ等、成立する例外を記録します。根拠のある同一指標の確定範囲は`20~30`として表示し、未確定の条件付き値や未取得値は「不明」とします。括弧から範囲を推定しません。ダウンはD、非攻撃技の攻撃発生等の適用対象外は表示可能です。
通常モードでは4項目、発生のみモードでは発生だけを判定します。

2026-11-06の追加採用方針により、`9(19)`のような括弧付き原典表記は、原則として括弧外の数値をゲーム用代表値に採用します。明確な矛盾がある場合は個別に扱い、元表記・判断を保存します。公式検証や範囲の確定とは別で、自動更新・一括置換はしません。ケンOD龍尾脚の発生はユーザー指定で9Fを採用しました。

foundとnot_foundを履歴に保存し、質問を消費します。
履歴には質問時のモードと結果のコピーを記録として保存し、表示には常に現在のモードを使います。ノーマルへ切り替えると過去の全履歴を4項目で表示し、発生のみへ切り替えると全履歴を発生だけにします。保存済みの未知値は「不明」と表示し、再検索や追加の質問消費は行いません。モードをまたいで同じ技は質問済みです。入力の表示は立ちの中央を省略し、太いSVG方向矢印と攻撃アイコンを使い、スクリーンリーダーには従来の入力文字列を提供します。
unknown、ambiguous、無効・未対応・質問済み入力は消費しません。取得成功・技なし・不明の通知は入力欄に表示せず、質問済み等の操作エラーは表示します。
5回目の有効な質問で最終回答に進み、回答確定まで正解を画面に表示しません。
質問フェーズでは「回答へ進む」から0〜4問でも最終回答へ移れます。質問回数・履歴・正解・表示モードは変わらず、キャラを選んで「回答確定」を押すまで結果は表示しません。5問未満なら「質問に戻る」で質問を続けられます。5問消費後と回答確定後は戻れません。
最終回答では候補1体を必須とし、正誤、正解、選択、履歴を表示します。
再プレイは設定画面へ戻り、履歴と回答を初期化して再抽選します。

本番データとFixtureは明示的な選択で切り替えます。初期表示は32キャラの採用データで、そのまま開始できます。保留入力は原典上の入力を保持し、技なしと区別します。
Fixtureは架空キャラ3体・架空技・架空数値で、実在キャラの性能を再現しません。

開発環境のみ「未検証の実データで試遊」を選択できます。初期選択は本番のままです。元のverified条件を緩めず、別の検証用解決処理で原典候補を表示します。第7段階から、このモードでも不明・未収録は消費せず、表示可能な値・確定範囲・原典範囲での技なしを1回として記録します。同一入力の衝突・質問済み入力は消費しません。原典範囲の技なしは現行パッチでの不存在を意味しません。必要項目が1つでも不明なら、その質問全体を消費しません。発生のみでは他3項目の不明は妨げません。

初期データの確定後は明示的な更新指示まで固定し、自動取得・自動更新しません。
開始状態以外、派生、構え中限定技、スーパーアーツ、ジャンプ通常技等のデータ収集は対象外です。通常状態からの構え移行自体は個別に採用を判断します。
ブラウザ内に正解情報は保持します。開発者ツールから隠すことは目的に含めません。
