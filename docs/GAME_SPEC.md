# ゲーム仕様

設定 → 質問 → 最終回答 → 結果 → 設定 の順で進みます。質問上限はロジックの設定値で、初期UIでは5回固定です。
Normalは発生・全体・ヒット時硬直差・ガード時硬直差を表示し、Hardは発生だけ表示します。開始時はNormal。質問・回答・結果のすべてのフェーズでパネル右上から切り替えられ、既存の全履歴も現在のモードで即時表示します。正解・質問数・履歴の記録自体は変わりません。内部の識別子normal／startupは維持します。
開始画面は「ゲームの説明」と「ルール・注意事項」を見出しと区切り線で分けます。説明文は16px、ルール本文は14px、両見出しは18pxです。概要とNormal／Hardの違いを説明し、ルール欄には質問回数、不明・技なし、質問済み入力、標準条件、OD・対象外入力、遠距離・D・代表値、溜め入力の操作を短くまとめます。末尾の収録範囲・対象パッチについての注意書きは表示しません。

第10段階から、原典との対応・明確な矛盾の有無を基準に採用し、原典に基づく収録範囲がcompleteのキャラクターから等確率で抽選します。出典のverificationやパッチ確認とは独立したadoption判定を使います。公式・実機での100%検証は採用要件にしません。
同じ一覧が回答候補になります。2体未満では開始できません。出題対象はデータから決定します。
回答画面はリリースの古い順に表示します。同時発売の初期18体は[公式キャラクター一覧](https://www.streetfighter.com/6/ja-jp/character)のルークから始まる順（ルーク、ジェイミー、マノン、キンバリー、マリーザ、リリー、JP、ジュリ、ディージェイ、キャミィ、リュウ、エドモンド本田、ブランカ、ガイル、ケン、春麗、ザンギエフ、ダルシム）とし、以降は追加順です。表示順だけを指定し、抽選候補の順序や確率は変更しません。未登録の将来キャラは末尾に元の相対順で表示します。

通常技はレバー中央（立ち）・下（しゃがみ）とP/K、L/M/H。必殺技はレバーの方向列とP/K、L/M/H/ODから選び、「質問する」で確定します。8ボタンは上段が弱P・中P・強P・弱P＋中P、下段が弱K・中K・強K・弱K＋中K。通常技では同時押しを無効化します。
溜め入力は4→6を[4]6、2→8を[2]8へ対応付けます。長押し時間は要求せず、中央を挟んでも入力を維持します。4または2の段階で候補を選んでも成立します。候補・入力状況・プレビュー・履歴の溜め側だけ黄色にし、反対側の矢印は通常色とします。スキーマ・inputKeyと原典の角括弧表記は維持し、ほかのコマンドへ推測変換しません。
必殺技の方向列はニュートラルで消えず、クリアで初期化します。同一方向の揺れは重複せず、一度離して同じ方向を入れる22等は保持します。時間制限・近似補正はありません。マウス／タッチのドラッグ、方向の個別タップ、方向キー・テンキーに対応し、離すとノブは中央へ戻ります（通常技は選択位置を保持）。
「質問する」を押した後は、成立・不明・重複にかかわらず入力済みコマンドと攻撃ボタンの選択をクリアし、レバーを中央（立ち）へ戻します。不明の短い結果表示、質問非消費、履歴・正解・モードは維持します。
必殺技で方向を入力すると、レバー下のコマンド表示・クリアのすぐ下に、その方向列で始まる対応モーションの候補を表示します。候補は出題対象全体から重複を除いて導出し、正解キャラでは絞りません。候補クリックで方向列を明示的に完成させ、攻撃ボタンは別に選びます。候補選択は質問を消費せず、自動補正・自動質問も行いません。未入力・不一致時は候補を表示せず、質問後やクリアで候補も消します。
1回転は右→右下→下→左下→左…と、その逆の右→右上→上→左上→左…のどちらの入力からも候補に出します。開始方向は自由です。表示は入力済み方向に一致する1つの候補にまとめ、時計回り／反時計回りを別の選択肢にしません。候補クリックで360へ明示的に補完でき、クリックせず一周回しても成立します。両方向は同じ技入力となり、重複質問できません。
モーションなし同時押し（奮迅脚）・未対応の複雑な入力・強度noneは質問候補から除き、元レコード・スキーマは維持します。強度なしレコードと個別ボタンの対応が未確定の場合は技なしへ変換しません。
個々のキャラが持つ入力一覧はUIへ渡しません。入力候補は出題対象全体の採用された基本版から導出します。フレーム値の不明を理由に選択肢から除かず、質問時に必要な値を判定します。

検索は基本版だけを対象とし、複数ならambiguous、1件で採用済みかつ必要な値が表示可能ならfoundです。保留技・通常状態が不明の技はunknownです。
0件で採用データのそのカテゴリがcompleteならnot_found、それ以外はunknownです。技なしは採用データセット内での不存在を意味し、ゲーム本体の全パッチで不存在と主張しません。同じ入力の保留・条件版が記録されている場合もunknownとし、不存在へ変換しません。
標準条件は通常状態・原則立ちの相手・画面中央・通常ヒット/ガード・非ホールド・派生なし、全体Fは空振り時です。下段のガードはしゃがみ等、成立する例外を記録します。根拠のある同一指標の確定範囲は`20~30`として表示し、未確定の条件付き値や未取得値は「不明」とします。括弧から範囲を推定しません。ダウンはD、非攻撃技の攻撃発生等の適用対象外は表示可能です。
距離依存の技は遠距離の原典値を標準とします。3ボタン、ODではない同時押し特殊技、ボタンなしのランは収録対象外とし、元レコードと出典を保持します。通常のOD入力は維持します。

foundとnot_foundを履歴に保存し、質問を消費します。
履歴には質問時のモードと結果のコピーを記録として保存し、表示には常に現在のモードを使います。Normalへ切り替えると過去の全履歴を4項目で表示し、Hardへ切り替えると全履歴を発生だけにします。保存済みの未知値は「不明」と表示し、再検索や追加の質問消費は行いません。モードをまたいで同じ技は質問済みです。入力の表示は立ちの中央を省略し、太いSVG方向矢印と攻撃アイコンを使い、スクリーンリーダーには従来の入力文字列を提供します。
unknown、ambiguous、無効・未対応・質問済み入力は消費しません。取得成功・技なし・不明の通知は入力欄に表示せず、質問済み等の操作エラーは表示します。
5回目の有効な質問で最終回答に進み、回答確定まで正解を画面に表示しません。
質問フェーズでは「回答へ進む」から0〜4問でも最終回答へ移れます。質問回数・履歴・正解・表示モードは変わらず、キャラを選んで「回答確定」を押すまで結果は表示しません。5問未満なら「質問に戻る」で質問を続けられます。5問消費後と回答確定後は戻れません。
最終回答では候補1体を必須とし、正誤、正解、選択、履歴を表示します。
再プレイは設定画面へ戻り、履歴と回答を初期化して再抽選します。
