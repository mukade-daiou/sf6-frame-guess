# ゲーム仕様

設定 → 質問 → 最終回答 → 結果 → 設定 の順で進みます。質問上限はロジックの設定値で、初期UIでは5回固定です。
通常モードは発生・全体・ヒット時硬直差・ガード時硬直差を表示し、発生のみモードは発生だけ表示します。開始後のモード変更はできません。

当該バージョンで通常技・必殺技の収録が完了し、出典・カテゴリ・収録技の検証が済んだキャラクターから等確率で抽選します。
同じ一覧が回答候補になります。2体未満では開始できません。キャラクターIDをコードに固定しません。

通常技は立ち・しゃがみ、P/K、L/M/H。必殺技はデータ全体から導出するモーション、P/K、L/M/H/OD/none。
個々のキャラが持つ入力一覧はUIへ渡しません。入力候補は出題対象全体の基本版のうち、少なくとも1体で発生データが確定しているものです。

検索は基本版だけを対象とし、複数ならambiguous、1件で必要な値と出典が検証済みならfoundです。
0件でそのカテゴリの収録完了が検証済みならnot_found、それ以外はunknownです。
条件付き値や未取得値は自動解決せずunknownにします。明示的な適用対象外は表示可能です。
通常モードでは4項目、発生のみモードでは発生だけを判定します。

foundとnot_foundを履歴に保存し、質問を消費します。
unknown、ambiguous、無効・未対応・質問済み入力は消費せず、その理由を表示します。
5回目の有効な質問で最終回答に進み、回答確定まで正解を画面に表示しません。
最終回答では候補1体を必須とし、正誤、正解、選択、履歴を表示します。
再プレイは設定画面へ戻り、履歴と回答を初期化して再抽選します。

本番データとFixtureは明示的な選択で切り替えます。初期表示は本番未収録です。
Fixtureは架空キャラ3体・架空技・架空数値で、実在キャラの性能を再現しません。
開始状態以外、派生、構え、スーパーアーツ、ジャンプ通常技等のデータ収集は対象外です。
ブラウザ内に正解情報は保持します。開発者ツールから隠すことは目的に含めません。
