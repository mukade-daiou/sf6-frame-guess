原典側の空中技表記には `j.HK` と上流の `7HK or 9HK`、`j.MK` と `j.mK` 等の差がある。これらは明示された空中入力として対象外に分類し、地上技への別名正規化は行っていない。ホールド、派生、スーパーアーツ、ドライブ行等も対象外として理由を保存した。

**奮迅脚KKは対象範囲に含むが未対応。** 通常状態から使用できる地上必殺技であり、現行仕様から除外する根拠はない。モーションなしの二ボタン入力を表す明示的な入力型が必要になる。単にmotionを空文字や5へ置き換えたり、ODへ統合したりしていない。意味とパッチが未確定の現段階ではモデル・UIの拡張を実施せず、ケンの必殺技coverageをpartialのまま保持した。

スクトゥムの構え移行は採用候補に残し、アーマー吸収による自動反撃は対象外に分けた。原典のPP/KK表記から弱＋中の組み合わせを特定する新たな証拠は得られず、OD候補すべてに `od_low_medium_pair_confirmation` を残した。通常開始技と同入力の自動反撃・派生を混在させていない。

全行を分類できたことと、現行パッチの収録範囲を認定できたことを区別し、両キャラともcoverageCompleteはfalseとした。
