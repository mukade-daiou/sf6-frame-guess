## 標準条件と表示・消費ルール

通常状態・原則立ちの相手・画面中央・通常ヒット/ガード・非ホールド・派生なしを標準とした。全体Fは空振り時。下段は立ちガードが成立しないため、原典のlow属性に基づきガード時だけしゃがみを例外として記録する。非攻撃の構え・移動技の攻撃発生は適用対象外とし、アーマー開始や派生受付を流用しない。

条件が残る値は、同じ指標の上下限が根拠から確定している場合だけ`20~30`形式で表示する。Zodにconditionalのrange（min/max・根拠URL）を追加し、有限値・上下限の順序・表示との一致・単一numericとの非併存を検証する。括弧付き表記を解析して範囲へ変換する処理は実装していない。

| 値・結果                                 | 表示                             | 質問の消費                    |
| ---------------------------------------- | -------------------------------- | ----------------------------- |
| 標準条件で選択できた値                   | 単一値                           | 1回                           |
| 同一指標の確定範囲                       | min~max                          | 1回                           |
| 範囲未確定のconditional、unknown、未収録 | 不明・未収録の案内               | 消費しない                    |
| ダウン                                   | D                                | 他の必要項目も表示可能なら1回 |
| 適用対象外                               | -                                | 他の必要項目も表示可能なら1回 |
| 原典範囲での技なし（試遊専用）           | 現行パッチの不存在は未確認と併記 | 1回                           |
| 衝突・無効・未対応・質問済み             | 理由を表示                       | 消費しない                    |

通常モードは4項目、発生のみは発生だけを判定する。必要項目が1つでも不明なら質問全体を消費せず、質問済みにもしない。初期フレームデータの確定後はユーザーの明示的な更新指示まで固定する。アプリ起動・ビルドに外部取得や自動更新を追加していない。

今回の実データには、標準条件内で上下限まで認定できた範囲を追加していない。範囲表示と消費ルールは架空の回帰テスト値で検証した。数値のない根拠を補うために範囲を作っていない。

## OD・奮迅脚とパッチの追加調査

ODの操作仕様はLP+MP／LK+MK。奮迅脚はモーションなしのLK+MKで、内部キーをODと分離したまま、11(9)を派生受付として攻撃発生から除外した。入力モデル上の混同は解消しているが、原典PP/KKの数値が指定ペアに対応することを新たに検証できてはいない。一般的な「2ボタンでOD」という説明だけでは、技別・パッチ別の対応確認に代用しない。

## ゲーム完成・本番化までの残作業

### 本番化に必須

1. **対象パッチと出典の対応を認定する。** 公式情報、または対象版と変更履歴を明示できる信頼できる資料で、2体の採用技が同じパッチであることを確認する。ゲーム本体での確認は有力な方法だが、唯一の方法とはしない。
2. **指定した入力への対応を確認する。** 2体のODが弱＋中で原典の性能に対応すること、奮迅脚がLK+MKに対応することを技別に確認する。
3. **そのパッチでの収録範囲を認定する。** 保存原典の全行分類を現在の対象版へ結び付け、採用・対象外・入力例外を確認する。単に候補数がそろったことをcompleteの根拠にしない。

本番データ生成、metadataと全出典のバージョン統一、Zod・ローダー検証、Fixtureと開発用試遊を無効にした通しプレイは、上記の確認後に行う。今回の未検証sourceをverifiedへ昇格させない。

### 不明表示を守れば、公開後にも改善できる

未解決4技の値は、不明として該当モードの質問を消費させなければ、ゲーム進行の必須修正ではない。2体とも5回の有効質問が可能なことを確認した。ただし、全フレーム値を確定したデータとして完成を宣言するには、これらの解決が必要になる。初期版で不明を残す場合は明示し、後からの数値更新もユーザーの更新指示を受けて行う。

弱・中竜巻のダウン後有利Fの詳細、条件説明の補足表示、独立した第二資料の追加、モバイル実機での操作確認は公開後にも改善できる。ダウン後有利Fは現在のD表示には不要。残り30キャラへの展開は今回行っていない。
