# デザイン適用記録

参照元はユーザー提供の `DESIGN.md`（Perplexity AI Style Reference）です。
配色・文字・コンポーネント規則はこの資料を優先し、ゲームの画面構成は依頼仕様に従います。

| 判断         | 資料の規則と適用                                                            |
| ------------ | --------------------------------------------------------------------------- |
| 背景とカード | Parchmentのページ、Soft Paperのカード、Warm Mistの1px境界、カード角丸16px   |
| 文字         | 指定代替のsystem-ui、通常400・見出し500。本文16px、操作ラベル14px、補助12px |
| 選択状態     | モード・技種別・回答キャラの選択済みチップのみTealの面を使用                |
| 操作         | Inkの主要ボタン、12px角丸。無効ボタンは境界線主体の6px角丸                  |
| 幅と余白     | 最大900px、節間32px、カード内16px、4px単位                                  |
| 画像と装飾   | 画像、グラデーション、大きい影を追加しない                                  |
| レイアウト   | 3段階のゲームに不要なサイドバーは追加せず、中央1カラムにする                |
| モバイル     | 操作を48px以上にし、履歴の4項目を2列で表示                                  |

資料の `--surface-button-fill: #27251` は不正な5桁の16進色です。同資料のInk `#27251e` を使用します。
独自フォントのファイルは提供されていないため、外部フォントの追加取得はしません。

## 第12段階の操作UI

既存のDESIGN.mdとユーザー指定の平面的なアケコン構成を実装対象として固定。外部の新しい視覚方向は追加しません。

| 判断     | 根拠と適用                                                                                                            |
| -------- | --------------------------------------------------------------------------------------------------------------------- |
| 基調     | 既存の暖色オフホワイト、Ink、Teal、カード16px、4px単位の余白を維持                                                    |
| 操作配置 | 指定どおり技種別→レバー・8ボタン→入力プレビュー・質問。700px以下は縦配置                                              |
| 攻撃色   | ユーザー指定に基づき攻撃ボタンだけ水色・黄色・赤。選択はTeal輪郭とaria-pressedを併用                                  |
| アイコン | 太い矢印を1個の自作SVGの回転で8方向へ展開。攻撃は自作の円とP/K、同時押しは弱・中の2個を合成                           |
| モード   | 質問パネル右上のセグメント。開始はノーマル、過去履歴には当時のモードを表示                                            |
| 出典     | 常時表示カードとフッターを廃止。ヘッダーの44px情報アイコンから帰属・出典・未検証状態へアクセス                        |
| 素材確認 | 公式アイコンの再配布許諾が確認できなかったため利用しない。公式Web利用規約・動画ポリシーをUI素材の配布許諾とは扱わない |

配色・文字・平面表現・狭い画面の8ボタン配置を、実ブラウザーの1280／768／390／320px画像で照合します。ビットマップ素材・筐体装飾・影やグラデーションの追加は行いません。
