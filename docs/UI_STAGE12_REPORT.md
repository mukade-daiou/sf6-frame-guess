2026-11-06実施。開始時はmain、HEADは`5bfb0d4`、作業ツリーはclean。第11段階の構成を維持し、UI・入力制御・必要な回帰テストだけを変更した。

## 変更内容

既存のDESIGN.mdを基準に、暖色オフホワイト・Ink・Teal・16pxカードを維持。技種別切替、レバーと8ボタン、入力プレビューと質問ボタンの順に配置した。700px以下ではレバーとボタンを縦に並べる。攻撃ボタンのみ弱を水色、中を黄色、強を赤で表示し、選択を輪郭とaria-pressedでも示す。

採用データの常設カード、通常画面のデータセット情報、フッターと非公式注釈、スタート時のモード選択を削除。出典・帰属・ライセンス・未検証状態はヘッダーの情報アイコンから参照できる。Fixture・開発用試遊は折りたたみ内に残した。

## レバーと入力

共通のLeverコンポーネントを使用し、Pointer Eventsとpointer captureでマウス・タッチを統一。四角いガイド、軸、ノブはSVGとCSSで描画する。方向の個別タップ、方向キー・テンキー・Home/PageUp/End/PageDownでの斜め入力にも対応。touch-actionはレバー領域だけnoneにし、ページ全体のズームを妨げない。

通常技は中央／下を保持し、単独の6攻撃ボタンで選択。必殺技は方向の変化を記録し、離してもコマンドは保持、ノブは中央へ戻る。同一方向の微動は追加せず、ニュートラルを挟んだ2回の下は22になる。受付時間や近似補正は追加していない。

入力状況は未入力・入力途中・候補一致・候補不一致／未対応を表示する。クリアは方向列と技選択だけを消し、質問数・正解・履歴は維持。対応モーションとボタンは全出題対象の入力一覧から導出し、正解キャラ固有の候補をUIへ渡さない。

8ボタンは常に同じ位置。通常技、未入力、未対応コマンドでは同時押しを選択できない。攻撃ボタンは選択だけを行い、「質問する」で質問を確定する。

## モーションなし・未対応入力

奮迅脚KKはレコード、採用状態、スキーマ、出典を維持したまま、ローダーの質問入力一覧とゲーム開始時の一覧から除外した。専用ボタンは追加せず、未入力のODと誤統合しない。

既存のマリーザ・スクトゥム通常版は`214 K / strength:none`。指定された8ボタンにはstrength:noneがないため、L/M/Hへ推測で割り当てない。強度なし原典レコードがある場合、個別ボタンの対応が未確定であることをunknownとして返し、技なしにしない。ODスクトゥムの明示的なOD入力は従来どおり独立して扱う。

溜め・360等の未対応表記も近い方向列に変換しない。採用済みデータは63技、今回の操作モデルでの質問候補は35入力。収録技数とUIで指定できる入力数は別である。

## モードと履歴

開始時はノーマル。質問フェーズだけパネル右上でノーマル／発生のみを変更できる。切替は正解キャラ、質問数、履歴を変えない。その時点の必要項目で質問を判定し、不明は消費せず履歴に追加しない。

成立した質問はモードと結果のコピーを保存する。履歴・結果の入力は共通のMoveNotationを使用し、立ちでは中央を省略、しゃがみ・必殺技はSVG矢印、ODは2個の攻撃アイコンで表す。スクリーンリーダー向けには従来のdisplayInputを保持する。過去の質問は再評価せず、モードを変えても同じ入力は質問済みとして拒否する。
