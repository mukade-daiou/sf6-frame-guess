# 第8段階：初期データ本番化の証拠確認

2026-11-06実施。**初期版として本番化できるキャラクターは0体**。ケン33技・マリーザ30技すべてにframe-search上の技名対応を確認したが、正式なバトルバージョンと各技の性能、弱＋中入力の対応を認定する証拠が不足している。本番data・第7段階の値・verification・coverageは変更していない。

通常モードで不明の4技は、それだけでは本番化を妨げない。技の収録範囲と値の充足を分け、不明値を補完せず質問を消費しない仕様を維持できる。一方、対象パッチや入力対応の未確認を、値が不明であることと同一視して認定を省略することはできない。

取得URL・UTC時刻・応答本文は `staging/sf6-frame-data-stage8/evidence/`、ローカル観察は `local-installation.json` に保存した。以前の通常技HTMLは第4段階の取得時刻のまま利用し、今回のブラウザー取得と区別した。

frame-searchの公開JavaScriptにページ送りの仕組みがあり、通常のブラウザーでNextを押すと2ページ目を取得できた。直接APIリクエストはHTTP 200でも空の行とトップページへの遷移指示だけであり、有効な技データとして扱っていない。ブラウザーの正規操作で取得した一覧を使い、制限回避や認証情報の利用は行っていない。

Windows PowerShellによるメタデータ照会はWSLのsocketエラーで実行できなかった。Linux側からmanifestと実行ファイルの文字列を読み取ったが、ゲーム画面の版表示や入力実測は確認していない。Steam起動・ゲーム起動・自動更新は行わず、新しいパッチへ対象を変更していない。

## パッチ番号・更新履歴・転載関係

比較対象は引き続き **Ver.2.0500.001（暫定）**。正式なtargetGameVersionはUNVERIFIEDを維持する。

[Steamの公式告知フィード](https://api.steampowered.com/ISteamNews/GetNewsForApp/v2/?appid=1364780&count=100&maxlength=0&feeds=steam_community_announcements&format=json)の100件は2024年9月まで含み、10月13日の配信告知と10月16日の映画公開告知を確認できた。しかし、取得した公式告知には2.0500.001という番号を見つけられず、10月16日のバトル修正を技別に照合する内容もなかった。映画の告知をゲーム修正の証拠にしない。フィードに記載がないことから「修正はなかった」とも推論しない。

[frame-searchのガイド](https://frame-search.com/guide?lang=en-us)はCapcom公式情報由来と記載する。Update Trackerも公式変更ページへのリンクを付けた要約で、sf6-senseiはSuperComboの正規化データである。これらの一致を、それぞれ独立した実機測定の一致として数えない。SuperComboの各値が公式表とは独立に測定されたことも今回立証できていない。

ローカルのbuildidや実行ファイルの1.0.0.34はバトル版番号とは別の識別子であり、10月13日の更新日時だけでも10月16日修正の反映は判定できない。ゲーム内の版表示、またはbuild IDとバトル版の対応を示す信頼できる記録が必要になる。

## 63候補と技別フレーム値の比較

| 対象     | 候補／対応する技名 | 基本通常技 | frame-search必殺技原典行 | 入力キー衝突 |
| -------- | ------------------ | ---------- | ------------------------ | ------------ |
| ケン     | 33／33             | 12／12     | 34行を分類               | 0            |
| マリーザ | 30／30             | 12／12     | 32行を分類               | 0            |

基本技の対応は、通常技の立ち／しゃがみ・強度・P/K、必殺技の技名・強度に基づく。ディマカイルスは原典の(1)を本体、(2)を派生として区別した。ホールド版、空中版、奮迅脚後の攻撃、構えの自動反撃・派生等も別行に分類している。奮迅脚本体は通常技ページにあるQuick Dashへ対応付けた。

この観測範囲で説明できない必殺技行や候補側の対応漏れはなかった。ただし、技名の対応は実際の入力ペアとの対応を証明せず、表示版とゲーム本体のパッチが未対応のため、正式なcoverage complete/verifiedには進めない。

発生・ヒット・ガードの3項目×63技＝189項目を比較し、184項目は数値またはD・適用対象外の表示が一致した。3項目はケンの通常龍尾脚L/M/Hの発生で、frame-searchは18/23/28、第7段階は立ち相手への発生21/25/30である。これはSuperCombo注記の初期空中限定判定との意味差として保持し、一致と数えたり値を置き換えたりしていない。残る2項目はケンOD龍尾脚の発生とマリーザODクアドリガのヒットで、候補の不明を維持した。

全体Fは別扱いとした。frame-searchのRecovery列は一律に空振り全体Fとは限らず、飛び道具等には省略表示もある。Recoveryを全体Fとして転記したり、発生・持続と加算したりしていない。以上は表示上の照合結果であり、184項目を現行パッチの検証済み値として認定したわけではない。

全63技の出典・取得時刻・対応名・原典行・比較結果・未確認事実・具体的な取得方法を `review.json.characters[].moves` に保存した。原典の分類は同JSONのinventoryにある。新しい第三者表を本番データへ転載せず、既存候補のCC BY-SA 4.0表示と帰属を維持した。

## OD10技と奮迅脚に必要な証拠

| キャラ   | 未確認の入力                                        |
| -------- | --------------------------------------------------- |
| ケン     | 214KK、236KK、236PP、623KK、623PP、モーションなしKK |
| マリーザ | 214KK、214PP、236KK、236PP、623PP                   |

PP/KKという一般表記や「2ボタン以上」という説明は、指定ペアでの性能の証拠として十分ではない。frame-search上にも各OD名はあるが、これだけで入力ペアや性能をverifiedにしない。奮迅脚の入力モデル上の対応は完成しているが、LK+MKによる実際の発動記録は未取得である。

具体的には、次の証拠を同じ対象版・同じセッションで取得する。

1. ゲーム内バージョン表示を記録し、その表示が比較対象のバトル版であることを確認する。異なる版なら今回の対象を自動変更しない。
2. クラシック、通常状態、ストックなし、中央、非ホールド・派生なしに設定する。相手は原則立ち、下段のガードだけしゃがみとする。
3. 入力履歴を有効にし、各技をLP+MPまたはLK+MKで実際に出す。技名・入力履歴・フレームメーターを一緒に記録する。
4. 攻撃発生、空振り全体、通常ヒット、通常ガードをそれぞれ対応付ける。奮迅脚・スクトゥム自体は非攻撃として扱い、反撃や派生の発生を流用しない。

個々の入力と取得方法はJSONにも保存した。既にインストールがあることは判明したが、今回はゲーム内計測へ到達できていない。必要なのは同じWeb表への再アクセスではなく、対象版と結び付く入力・性能の記録である。

| 技                   | その値を確定するための証拠                                                                     | 不明のままの扱い                       |

| ケンOD龍尾脚         | LK+MKの入力履歴と、立ち相手に初めて当たる判定のフレーム記録。初期空中限定判定と区別            | 必要な発生が不明のため両モードで非消費 |

**この4技を不明のまま残す初期版は可能**と判断する。技が存在し、対象入力とパッチの対応、収録範囲を検証できれば、値の一部が不明でも技を欠落扱いにする必要はない。ローダーもcoverageと値の充足を分離しており、架空Fixtureを用いた追加テストで、収録完了・出典検証済みのキャラが不明値を持っても対象に残り、該当質問だけunknownになることを確認した。実データをテストのためにverifiedへ変更していない。

今回は、上記とは別の以下3条件が満たせず、本番化できない。

| 必須条件                         | 現状                                                                 | 満たすための証拠                                                   |
| -------------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 正式な対象パッチと全採用技の対応 | 未確認                                                               | ゲーム内版表示と同版の技別計測、または版・変更履歴を特定できる資料 |
| OD・奮迅脚の指定ペアへの対応     | 11入力で未確認                                                       | 入力履歴と技名・性能を同時記録した対象版の証拠                     |
| そのパッチでの採用範囲の完全性   | 観測した表では63候補と原典を対応付けたが、対象版への結び付けが未確認 | 同版のクラシック技一覧と、全行の採用／対象外判断                   |

したがって初期データセットは未確定のまま保持し、本番metadata・charactersは変更していない。開発用試遊を外した通しプレイは、2体を本番化できた場合という実施条件を満たさないため行っていない。第7段階の試遊はそのまま利用できる。
