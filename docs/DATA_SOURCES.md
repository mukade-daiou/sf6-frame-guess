# 出典・帰属方針

ゲームはSuperCombo WikiおよびRyoSogawa/sf6-sensei由来のコミュニティデータと、CAPCOM公式フレーム表に基づくレコードを使用しています。出典区分と権利表記は技レコードの `source` に記録しています。フレームデータの対象パッチは未確認です。

コミュニティ由来データの出典・改変内容・CC BY-SA 4.0については [NOTICE](../NOTICE) と [data/NOTICE](../data/NOTICE) を参照してください。このライセンスの表記はコミュニティ由来部分に適用されます。公式由来レコードにはCAPCOMの権利表記を保持しています。

操作アイコン「Punch」「Barefoot」はLorc作、Game-icons.netのCC BY 3.0素材です。原典と表示上の変更は [NOTICE](../NOTICE) に記載しています。

付属Fixtureのキャラクター、技、フレーム値、ゲームバージョンはすべて架空です。
出典URLの `example.invalid` は実データの参照元ではありません。
FixtureのみにCC0-1.0を指定しています。SF6や外部サイトのデータに同じ条件を適用するものではありません。

実データ導入時は、元URL・取得日時・ゲームバージョン・公式/コミュニティの区分・帰属文・利用条件・検証状態を記録してください。
アプリの「データの出典・帰属」では、読み込んだデータの出典と操作アイコンの帰属を確認できます。
異なるパッチを混ぜず、未確認の値はunknown、未取得表示はnullとしてください。
