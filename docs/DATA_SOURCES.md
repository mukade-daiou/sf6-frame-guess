# 出典・帰属方針

本番のSF6フレームデータは未収録です。実データの取得、数値の推測、ライセンスの推測は行っていません。

付属Fixtureのキャラクター、技、フレーム値、ゲームバージョンはすべて架空です。
出典URLの `example.invalid` は実データの参照元ではありません。
FixtureのみにCC0-1.0を指定しています。SF6や外部サイトのデータに同じ条件を適用するものではありません。

実データ導入時は、元URL・取得日時・ゲームバージョン・公式/コミュニティの区分・帰属文・利用条件・検証状態を記録してください。
アプリ下部に、読み込んだデータ全体の帰属情報を表示します。正解キャラに限った出典表示はしません。
異なるパッチを混ぜず、未確認の値はunknown、未取得表示はnullとしてください。
